# 功能说明

这份文档列出「我的一周」能做什么、数据放在哪、同步和加密是怎么工作的。怎么安装和部署见 [README](../README.md)。

## 周页面

- **七个日期格子**：本周的进度条。每个周几固定一个颜色（周一橙、周二黄、周三绿、周四青、周五蓝、周六紫、周日粉），当天日记写得越多，格子颜色越深，像油漆色卡往下走。今天的格子有斜纹，还没到的日子颜色更淡。点格子进入那天的日记。
- **记一件事**：七个格子下面的输入框，边框是选中那天的颜色。左边选周几，回车记下。
- **这周的事**：只标周几，不带时间。越近的日子越靠上，新记的放在那天最上面。
  - 每条前面是当天颜色的圆点，按住圆点可以在同一天之内上下拖动排序，其他条目会滑开让位，横线标出落点。
  - 双击文字进入修改；修改时右边才出现 ×，点一下变红，再点一下删除（平时不显示，免得误点）。
  - 每天的标题旁有「收起 / 展开」，收起状态只存在这台设备上。
- **周目标**：可勾选的清单，双击修改。
- **本周复盘**：自由文本。
- **快速跳转**：格子下面有「周目标 ↓」「本周复盘 ↓」；滚下去后右下角有「↑ 顶部」。
- **文件里的其他内容**：`.md` 里四个固定标题以外的段落（旧版本同步冲突时留下的「冲突副本」也在这里，可以直接删掉），原样显示和保存，可以直接编辑。

## 日记页面

- 标题下面是一个当天颜色的输入框，左边显示此刻的时间。写一句、回车或点「记」，新的一条出现在最上面，自动带上写下它的时间。
- **按时间倒序**，越近越靠上；改了时间会立刻重排。子条目跟着父条目走，同一层也倒序。
- **时间戳颜色随钟点渐变**：凌晨靛蓝 → 清晨玫瑰 → 上午琥珀 → 正午绿 → 下午蓝 → 傍晚紫 → 深夜靛蓝。
- **双击时间戳修改**；清空就是不带时间。在过去某天补写的条目，时间旁标一个「补」字。
- **分点和缩进**：在某一条里回车，接着在它下面新起一条；Tab 缩进、Shift+Tab 退回；空行按退格删掉；上下键在各条之间跳。手机上编辑时底部有缩进按钮。连续写的时候先不重排，离开编辑再按时间排好。
- 顶层圆点之间有一条浅灰色的时间线。
- 「这周的事」里属于这一天的条目，用当天色卡作底色置顶显示。

## 日记里的图片

- **加图**：输入框右边的图片图标选图（可以多选）；也可以在输入框或某一条里直接粘贴（电脑上的截图、复制的图片）。给已有的条目加图：点进那一条，底部工具栏点「图片」。
- **缩略图和大图**：日记里只显示缩略图，点一下全屏看大图；安卓上按返回键先关大图。
- **解码中**：选好图后马上出现调暗的预览和「解码中」，一张张处理，好了换成缩略图；解码中点右上角的 × 可以取消。
- **删除**：点进条目开始编辑，缩略图右上角出现 ×；也可以在大图界面点「删除这张」。**删除会同步到所有设备和服务器，无法恢复。**
- **压缩**：图片在设备上先压缩成 JPEG（大图长边最多 1600 像素，缩略图 320 像素）再保存，一张一般几百 KB。支持 JPG、PNG、WebP、GIF；iPhone 的 HEIC 要先转成 JPG。
- **文件里怎么写**：`.md` 里每张图只有一行引用 `![](img:ID)`，图片本身不在 `.md` 里。所以「导出本周」导出的 `.md` 不带图片。
- **同步**：开了同步，图片会传到服务器，别的设备显示时才下载（先缩略图），存在本机。开了端到端加密的账号，图片也是加密后才上传的。没开同步时，图片只在这台设备上。

## 语言

界面语言跟随系统：中文系统显示中文，其他显示英文。星期、日期、提示和报错都会跟着换。`.md` 文件里的标题（`## 周目标` 等）永远是中文，这是数据格式，两种语言的设备可以同步同一份数据。调试时在网址后面加 `?lang=en` 或 `?lang=zh` 可以临时指定。

## 草稿

日记、这周的事、周目标三个输入框里写了还没记下的字，每敲一个字就存在本机。关掉 App 或刷新页面再打开，字还在框里，旁边标着「未记下」；「这周的事」连选的周几也记得。回车或点「记」之后草稿清掉。草稿只在这台设备上，不同步。

## 数据：一周一个 Markdown 文件

每周一个 `2026-W42.md`（ISO 周号），格式见 README。用任何编辑器都能打开和修改，页面会读回改动。

数据可以放在这几个地方，可以同时用：

| 位置 | 说明 |
|---|---|
| 本机存储 | 浏览器或 App 内部，总会存一份。App 卸载时会被清掉。 |
| 本地文件夹 | 电脑上的 Chrome / Edge，或者安卓 App，都可以「连接数据文件夹」。文件是明文、属于你，卸载 App 不会删。在编辑器里改了文件，切回页面会读回来，并同步上去。 |
| 同步服务器 | 可选。各设备通过它同步，见下文。 |

导出 / 导入：周页面底部可以导出本周的 `.md`（App 里会弹出系统分享面板），也可以一次导入多个 `.md`。

## 同步

- 每台设备在本地都有完整的数据，离线照常写，联网后自动同步：每 30 秒一次，切回页面、恢复联网、写完 2 秒后也会触发。
- 服务器给每一周算一个版本号（内容的哈希）。推送时带上「基于哪个版本改的」，版本对不上，服务器就拒绝覆盖。
- **冲突**：两台设备改了同一周，后推送的那台不会覆盖前一台。这时按**条目**三方合并（`web/js/merge.js`，对照「上次对齐的那份、本设备、服务器」三份）。每个条目行尾有一个 ID（见下面的文件格式），靠它认出「同一条」，改了字也认得出：两边各加的条目都留下；一边删了、一边改了字的，改了的留下；一边改字、一边勾选或挪位置的，两样都保留；「同一条被两边改成不同的字」时，**后推送的那台设备为准**，并提示被替换的是哪一条，被替换的那一版存在本机「历史版本」里。不再生成「冲突副本」。
- 页面标题旁的小胶囊显示同步状态：绿色「已同步 HH:MM」、黄色「有提醒」（比如服务器上读不出某一周）、红色「同步出错」。点它跳到同步设置。
- 服务器每次覆盖前会保留旧版本（`.history/`，每周最近 50 份）。
- 服务器主人可以给熟人开账号，每人一个独立目录，互相看不到。
- **图片**单独走 `/api/images/<ID>`（上传、下载、删除），不进周文件。新加的图进待上传队列，联网后传；别的设备显示时才下载；用户删图时服务器上的文件也真的删掉，不进 `.history`，不留副本。每张最大 4 MB、每个账号总量 500 MB（可用环境变量调整）。

## 端到端加密

开启后，服务器只存密文，服务器主人也看不到内容。本机和本地文件夹里的文件仍然是明文，照常可以改。

**怎么用**

1. 在一台已经同步好的设备上，打开周页面底部的「同步」，点「开启端到端加密…」。
2. 页面显示一串**恢复码**（54 个字符，四个一组）。把它存进密码管理器或截图保存，勾选「我已经把恢复码存好了」，再点「开启加密」。服务器上已有的数据会全部换成密文，旧的明文历史版本也会被删除。
3. 在其他设备上填好令牌后，页面会提示「这个账号开了端到端加密」，输入恢复码即可。随时可以在已同步的设备上点「显示恢复码」查看。

**怎么实现的**

- 密钥是第一台设备随机生成的 256 位密钥，只存在设备上，服务器从来没见过。恢复码就是这把密钥本身，用 base32 写出来，末尾带 2 位校验，抄错一个字能发现。
- 每一周用 AES-256-GCM 单独加密，每次随机 IV；周号作为附加认证数据，服务器把 A 周的密文挪到 B 周会解密失败。全部用浏览器自带的 WebCrypto，不依赖第三方库。
- 服务器记录账号是否加密，以及密钥指纹（SHA-256 的前 4 字节，用来认出密钥对不对）。开了加密的账号，服务器拒收明文，免得一台还没装密钥的设备把明文传上来。
- 冲突在设备上解密之后再合并，服务器全程只经手密文。
- 图片同样用 AES-256-GCM 加密，附加认证数据是图片的键（ID 或 ID + `t`），服务器把 A 图的密文挪成 B 图会解密失败。开了加密的账号，服务器只收以 `MYWEEK-E2EE/1` 开头的图片密文。

**要知道的事**

- **恢复码丢了，而且所有设备都丢了，服务器上那份就再也解不开了**，谁都没办法，包括服务器主人。本地文件夹里的明文文件不受影响。
- 服务器能看到的只有：你有哪几周的数据、每周大概多大、什么时候改的。看不到内容。
- 开启加密后，就不能再在服务器上直接改 `.md` 了。要手动改，请在本地文件夹里改。
- 用网址版时，页面代码是服务器发给你的，理论上服务器主人可以改页面、截走恢复码。安卓 App 的代码打包在 App 里，从公开仓库构建，不经过服务器，信任更少。
- 目前不支持关闭加密。

## 安卓 App

- 和网页是同一套代码，用 Capacitor 打包。
- 同步时需要填服务器地址和令牌。
- 「连接数据文件夹」会打开系统的文件夹选择器，选一个文件夹（比如 `文档/我的一周`）后，授权会一直保留。
- 「导出本周」会弹出系统的分享面板，可以存到文件或发给别人。
- **返回键**：在日记页按返回键回到周页面，不会直接退出；大图、新功能弹窗开着时，返回键先关它们。在周页面按返回键才退出 App。
- **新功能弹窗**：更新后第一次打开，会弹出这一版的新功能，点「知道了」才算看过；全新安装不弹。网页版更新后也一样。
- **新版本提醒**：发现新版本时，页面底部出现「新版本 vX · 点这里下载」。点了先说明怎么装，再用系统浏览器打开安装包。✕ 表示这一版先不提醒。
  - 去哪查：先问 GitHub Releases，连不上再问 Gitee。下载链接用回答了的那一边的 `my-week.apk`。
  - 什么时候查：**开了同步的**，打开 App 或切回来时自动查，一天最多一次。**没开同步的**从不自动联网，只有点周页面底部的「检查更新」才查。
  - 只读公开的发布信息，不带令牌，也不带任何日记内容。只给链接，不自动下载、不自动安装。
  - 直接覆盖安装，数据都在。**不要先卸载**：没连文件夹、也没开同步的话，卸载会清掉所有日记。安卓会核对签名，提示「签名不一致」的安装包不是正版，不要装。
  - 网页版不用这个，它自己会整版更新。
