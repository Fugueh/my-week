# v0.4.1：日记条目可以删除了

0.4.0 之后的一个小版本：补上日记条目的删除，加图更可靠，多张图会自动换行。这一版不会再弹「新功能」窗口。

## 日记条目可以删除了

- 点进某一条开始编辑，这一条的右上角出现 ×；点一下变红，再点一下删除。平时不显示，免得误点。
- 这一条下面有缩进的子条目时，会连它们一起删。
- 条目里的图片也会一起删，包括服务器和其他设备上的，**无法恢复**。
- 以前带图片的条目删不掉（空行按退格只对没有图片的条目有用），现在可以了。

## 加图更可靠

- **失败不再悄悄消失**：有的图解不开时，以前只在页面最底部的状态栏闪一句，容易漏看，看上去就像图片自己不见了。现在它会留在原地，变成标着「没加上」的红色格子，鼠标放上去能看到原因，点右上角 × 才去掉；别的图照常能记下。
- **一张一张解码**：连续选好几张图时，改成排队一次解一张，不会几张大图同时解码把手机内存撑爆。
- 解不开的文件（比如不是图片）只多试一次，不再白等几秒。

## 多张图自动换行

- 缩略图的大小跟着可用宽度走：窄屏（手机）一行至少 3 张，宽屏每张最大 96 像素，放不下的自动换到下一行。
- 输入框上方等着一起记下的图也一样。

## 升级

- **安卓 App**：有新版本时 App 会提醒，点底部的提示下载安装，直接覆盖，**不要先卸载**，日记、草稿、同步设置都会保留。国内下载可以用 [Gitee](https://gitee.com/fugueh/my-week-apk/releases)。
- **网页版**：已经更新，打开后会自动换成新版本（关掉再打开两次）。
- **自己部署服务器的**：这一版没有改服务器接口，不用重新部署；想一起更新页面就照常 `docker compose up -d --build`。
