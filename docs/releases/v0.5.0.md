# v0.5.0：Windows 桌面版

这一版新增 **Windows 桌面版**。安卓 App 和网页版没有变化，也不会弹「新功能」窗口。

## 下载

在这个发布的附件里二选一：

- `my-week-setup-0.5.0.exe`：**安装包**。可以选装到哪里，会建开始菜单和桌面快捷方式「我的一周」。
- `my-week-0.5.0-win-x64.zip`：**免安装**。解压到任意位置，双击里面的 `my-week.exe`。

需要 64 位 Windows 10 或 11。安装包没有代码签名，第一次运行时 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

## 数据存在哪

- 日记默认存在 **`文档\MyWeek`**，一周一个 `.md` 文件（比如 `2026-W44.md`），用任何编辑器都能打开和修改。在编辑器里改过，切回 App 会自动读回来。
- 周页面最底下显示数据文件夹的完整路径：
  - **「在文件管理器中打开」**：用资源管理器打开这个文件夹。
  - **「换一个文件夹」**：换到别的地方，比如网盘的同步目录。
- 卸载 App 不会删掉这些 `.md` 文件。
- 图片和设置存在 App 自己的目录 `%APPDATA%\MyWeek`。想在别的设备上也看到图片，请开同步。

## 同步

和手机一样，在周页面最底下的「同步」里填上服务器地址和令牌，电脑和手机就能用同一份日记。

## 升级

- **安卓 App**：这一版安卓没有改动，可以不升级。想升级的话照常点 App 底部的提示下载安装，直接覆盖，**不要先卸载**。国内下载可以用 [Gitee](https://gitee.com/fugueh/my-week-apk/releases)。
- **网页版**、**自己部署服务器的**：不用做任何事。
