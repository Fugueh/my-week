# v0.4.2：手机上一次选多张图，不再只有第一张能上

0.4.1 之后的一个修复版：**手机上一次选好几张图，只有第一张能加上、后面的全部失败**，这一版修好了。这一版不会再弹「新功能」窗口。

## 修了什么

- 在安卓手机上从相册一次选多张图，以前只有第一张成功，其余都显示「没加上」，提示「解不开（image/jpeg）」。图片本身没有问题。
- **原因**：安卓选出来的文件只在刚选完的一小会儿稳定可读。第一张是马上开始处理的，所以总能成功；排在后面的要等前面的处理完才轮到，那时已经读不了了。电脑上没有这个问题，所以之前怎么试都复现不了。
- **现在**：一选完图，就把选中的图全部先读进内存，之后都从内存里处理，不再依赖原文件。选几张都行。
- 如果有某个文件真的读不了，会显示「没加上」，提示「读不了这个文件，请重新选一次」，不再误报成「解不开」。

## 其他

- 内部的版本号规则调整了（给自己出测试包时不会再遇到「无法降级安装」），用户这边没有变化。

## 升级

- **安卓 App**：有新版本时 App 会提醒，点底部的提示下载安装，直接覆盖，**不要先卸载**，日记、草稿、同步设置都会保留。国内下载可以用 [Gitee](https://gitee.com/fugueh/my-week-apk/releases)。
- **网页版**：已经更新，打开后会自动换成新版本（关掉再打开两次）。网页版选多张图本来就没有这个问题。
- **自己部署服务器的**：这一版没有改服务器接口，不用重新部署；想一起更新页面就照常 `docker compose up -d --build`。
