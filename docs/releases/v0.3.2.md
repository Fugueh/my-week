# v0.3.2：App 会提醒你更新了

从这一版开始，安卓 App 有了新版本会告诉你，不用再等别人通知。

## 新版本提醒

- 有新版本时，页面底部出现「新版本 vX · 点这里下载」。点了先说明怎么装，再用系统浏览器打开安装包。
- **去哪查**：先问 GitHub，连不上再问 Gitee（[fugueh/my-week-apk](https://gitee.com/fugueh/my-week-apk/releases)），国内也能查到、下载到。
- **什么时候查**：
  - 开了同步的：打开 App 或切回来时自动查，一天最多一次。
  - 没开同步的：**从不自动联网**，只有点周页面底部的「检查更新」才查。
- 只读公开的发布信息，不带令牌，也不带任何日记内容。只给链接，不会自动下载或安装。
- 点 ✕ 表示这一版先不提醒，有更新的版本时会再提醒。

**怎么装**：下载后直接点开安装，覆盖现在的 App，日记、草稿、同步设置都会保留。**不要先卸载。** 如果安卓提示「签名不一致」或要求先卸载旧版，说明这个安装包不是正版，不要装。

## 其他
