# v0.4.0：日记可以插入图片了

这一版最大的变化：**日记里可以放图片**，图片会同步到你的其他设备。另外加了英文界面，安卓的返回键也更顺手了。

更新之后第一次打开，会弹出一个「新功能」窗口，把下面这些简单说一遍，点「知道了」就不再出现。

## 日记里的图片

- **加图**：日记页输入框右边有个图片图标，点它选图（可以一次选好几张），图片会先出现在输入框上方，点「记」跟文字一起记下。给已经记下的条目加图：点进那一条，底部工具栏点「图片」。
- **电脑上可以直接粘贴**：截图、复制的图片，在输入框或某一条里按 Ctrl+V 就行。只有剪贴板里有图时才接管，粘贴文字照常。
- **缩略图和大图**：日记里显示缩略图，点一下全屏看大图。安卓上按返回键先关大图。
- **有反馈**：选好图后马上出现调暗的预览和「解码中」，好了换成缩略图。手机上大图解码要几秒，不用担心卡住了；想取消就点预览右上角的 ×。
- **删除**：点进条目开始编辑，缩略图右上角会出现 ×；在大图界面点「删除这张」也行。
- 图片会先在你的设备上压缩（长边最多 1600 像素），一张一般几百 KB。支持 JPG、PNG、WebP、GIF；iPhone 的 HEIC 要先转成 JPG。

### 图片的同步和删除

- **同步到其他设备**：开了同步的话，图片会传到服务器，别的设备显示它的时候才下载（先下缩略图，点开大图再下大图），不会一下子把所有图片都拉下来。
- **加密**：开了端到端加密的账号，图片也是在你的设备上加密之后才上传的，服务器只存密文。
- **删了就是真删了**：像社交媒体一样，你删掉一张图，服务器和其他设备上的这张图也会一起删掉，**无法恢复**。删之前会再问你一次。断网时删的，联网后会补上。
- **没开同步**：图片只存在这台设备上，卸载 App 或清除浏览器数据会一起清掉。想保住，请开同步。
- **导出本周**导出的 `.md` 里只有图片的位置标记，不带图片本身。
- 在别的设备上看不到图时，会显示「图片看不到：已被删除，或现在连不上服务器」。

## 英文界面

界面语言跟着手机或电脑的系统语言走：中文系统显示中文，其他显示英文。你的日记文件格式不变，中文和英文设备可以同步同一份数据。

## 其他

- **安卓返回键**：在日记页按返回键，回到周页面，不再直接退出 App。（在周页面按返回键才会退出。）
- 「加一个目标」旁边的按钮改成了 `+`。

## 升级

- **安卓 App**：有新版本时 App 会提醒，点底部的提示下载安装，直接覆盖，**不要先卸载**，日记、草稿、同步设置都会保留。国内下载可以用 [Gitee](https://gitee.com/fugueh/my-week-apk/releases)。
- **网页版**：已经更新，打开后会自动换成新版本（关掉再打开两次）。
- **自己部署服务器的**：要重新部署一次（`docker compose up -d --build`），图片同步才能用。旧服务器上新版 App 也能用，只是图片不会同步，每轮同步会提示「图片没能同步」。
- 图片上传大小：每张最多 4 MB，每个账号总量最多 500 MB；这两个数可以用环境变量 `MAX_IMAGE`、`IMAGE_QUOTA` 调整。
