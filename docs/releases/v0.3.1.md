# v0.3.1：没记下的字不会再丢

有用户反馈：在输入框里写了一半，退出 App 再打开，字就没了，之前也没有任何提示。这一版修好了。

## 草稿自动保存

- 日记、这周的事、周目标三个输入框里写了还没记下的字，**每敲一个字就存在本机**。关掉 App、切走被系统回收、刷新页面，再打开时字还在框里。
- 框里有没记下的字、而你又没在输入时，旁边会标一个「未记下」，一眼就能看出还有一句没记。
- 「这周的事」连选的周几也记得。
- 回车或点「记」之后，草稿自动清掉。
- 草稿只存在这台设备上，不同步到其他设备：还没记下的字不算日记内容。

## 日记输入改成了输入框

日记页面标题下面原来是一根当天颜色的横线，现在改成和「这周的事」一样的输入框：边框是当天的颜色，左边是此刻的时间，右边多了一个「记」按钮。手机上不用找回车键，点「记」也能记下。

## 升级

- 安卓 App：下载下面的 `my-week.apk` 覆盖安装，数据不受影响。
- 网页版已经更新，打开后会自动换成新版本（正在输入时会等你写完，或在底部提示「有新版本，点这里刷新」）。
